# Calificacion Estudiantil 
Este ejercicio consiste en crear un formulario que permita capturar las 4 notas de un estudiante 
y medir mediante el resultado si el estudiante pasa o reprueba.

# Herramientas Utilizadas :
C#

.NET Framework

Visual Studio 2022

# Uso o Ejecución

Primero se debe clonar el repositorio desde GitHub usando el siguiente comando:

Git clone https://github.com/ALVELISSANTANA/Desarrollo-De-aplicaciones/edit/main/README.md

Luego se abre el archivo .sln del proyecto en Visual Studio.

Después se compila el proyecto para verificar que todo funcione correctamente.

Finalmente se ejecuta la aplicación presionando F5 o haciendo clic en el botón Iniciar en Visual Studio.

Al ejecutarse, se abrirá el formulario principal del sistema.
